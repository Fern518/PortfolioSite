Custom Macropad

Project Description

This project involves the creation of a custom PCB-based macropad designed specifically for the Hack Club Blueprint program. The macropad is intended to enhance productivity and provide customizable shortcuts for various applications.

Technologies Used

  • PCB Design Software (e.g., KiCad)
  • Microcontroller (e.g., ATmega32U4)
  • Mechanical Switches
  • 3D Printing for the case
  • Firmware Development (QMK)

Features

The macropad includes:

  • Customizable key mappings
  • RGB backlighting
  • Multiple layers for different profiles
  • Compact design for portability

Impact

This project not only showcases my skills in hardware design and programming but also serves as a valuable tool for students and members of the Hack Club community, allowing them to enhance their workflow and creativity.
