Gravity Flip

A 2D puzzle platformer where gameplay centers around flipping gravity.

Project Overview

Gravity Flip is a unique 2D puzzle platformer that challenges players to think creatively about gravity. Players navigate through various levels, solving puzzles and overcoming obstacles by flipping the direction of gravity.

Development Insights

This project was developed using Unity and C#. The main focus was on creating engaging gameplay mechanics that allow players to manipulate gravity in innovative ways. The game features a variety of levels, each designed to test the player's problem-solving skills.

Technologies Used

  • Unity
  • C#
  • Adobe Photoshop (for graphics)
  • FMOD (for sound design)

Gameplay Mechanics

Players can flip gravity at will, allowing them to walk on ceilings and navigate through intricate level designs. The game includes various puzzles that require players to think outside the box and use gravity manipulation to progress.

Conclusion

Gravity Flip has been a rewarding project that has taught me a lot about game design and development. I hope to continue expanding on this concept in future projects.
