Damned Waters

A short narrative-based horror game set at an abandoned hydroelectric dam.

Project Overview

Damned Waters is a unique horror game that immerses players in a chilling narrative set in an abandoned hydroelectric dam. Players must navigate through eerie environments, solve puzzles, and uncover the dark history of the dam.

Gameplay Mechanics

The game features a mix of exploration, puzzle-solving, and narrative-driven gameplay. Players interact with various objects in the environment to progress through the story, facing challenges that test their wits and courage.

Technologies Used

  • Unity Engine for game development
  • C# for scripting
  • Blender for 3D modeling
  • Adobe Photoshop for texture creation

Challenges Faced

One of the main challenges was creating an immersive atmosphere that effectively conveyed horror elements. This involved careful attention to sound design, lighting, and environmental storytelling.

Conclusion

Damned Waters has been a rewarding project that allowed me to explore narrative design and game mechanics. The feedback from playtesters has been invaluable in refining the experience.
