# Portfolio Site

## Overview
This portfolio site showcases various projects and provides detailed write-ups for each. It serves as a personal portfolio for showcasing skills, experiences, and projects.

## Project Structure
The project is organized as follows:

```
PortfolioSite
├── index.html                # Main HTML file for the portfolio site
├── resume.html               # Contains the individual's resume
├── pages                     # Directory for project write-ups
│   └── projects              # Subdirectory for project pages
│       ├── hackpad          # Hackpad project write-up
│       │   └── index.html   # Detailed description of the Hackpad project
│       ├── gravity-flip     # Gravity Flip project write-up
│       │   └── index.html   # Insights into the Gravity Flip project
│       ├── tech-support      # Tech Support Business project write-up
│       │   └── index.html   # Explanation of the Tech Support Business
│       ├── damned-waters     # Damned Waters project write-up
│       │   └── index.html   # Narrative and gameplay elements of Damned Waters
│       └── beneath-the-surface # Beneath the Surface project write-up
│           └── index.html   # Features and design of Beneath the Surface
├── css                       # Directory for styles
│   └── style.css             # Styles for the portfolio site
├── js                        # Directory for JavaScript
│   └── main.js               # JavaScript code for interactivity
├── images                    # Directory for project images
│   ├── Hackpad               # Images related to the Hackpad project
│   └── Gamedev               # Images related to game development projects
│       ├── beneathSurface    # Images for Beneath the Surface project
│       └── damnedWaters      # Images for Damned Waters project
└── README.md                 # Documentation for the project
```

## Features
- **Responsive Design**: The site is designed to be responsive and accessible on various devices.
- **Project Showcase**: Each project is displayed in a card format with a brief description and a link to a detailed write-up.
- **Interactive Elements**: JavaScript is used to enhance user interaction, such as scrolling through project cards.

## Setup Instructions
1. Clone the repository or download the project files.
2. Open `index.html` in a web browser to view the portfolio site.
3. Navigate through the projects and click on "View Project" buttons to access detailed write-ups.
